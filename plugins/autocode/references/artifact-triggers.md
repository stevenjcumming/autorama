# Artifact Triggers & Generation Reference

## Trigger Conditions

| Artifact | Trigger | Generated By |
|----------|---------|--------------|
| Justification | Changed file matches `justification.categories` glob in config | PostToolUse hook creates the template; task-runner fills it (Step 6) |
| Decision | Choice made between multiple valid approaches | Coder, inline |
| Risk | Changes touch security, auth, payment, or migration paths | PostToolUse hook creates the template; task-runner fills it (Step 6). Coder writes inline risks the hook cannot detect |
| Debt | Shortcut taken or retry_count > 0 | Coder, inline |
| Review Hint | Test files modified, >3 files changed, or subtle implications | PostToolUse hook creates the template; task-runner fills it (Step 6) |
| Assumption | Task required inferring unstated requirements | Coder, inline |

## Path Pattern

`{SPEC_DIR}/artifacts/{dir}/{task_id}_{name}_{timestamp}.md`

where `{dir}` is one of the literal directory names created by setup-artifacts.sh:
`justifications/`, `decisions/`, `assumptions/`, `risks/`, `debt/`, `review_hints/`

## Justification Category Configuration

Category globs come from `justification.categories` in `.claude/autocode.yml`. Precedence:

1. If `.claude/justifications.yml` exists, its top-level `categories:` **replaces** autocode.yml's `justification.categories` entirely (no merging).
2. Within whichever file is active, the **first matching category wins** when a file path matches multiple category globs.

Categories not present in the shipped config (like `api_change` below) have no glob to match; they rely on coder judgment when categorizing a changed file.

## File Categories

Determine category based on file path:

| Category | Path Pattern | Notes |
|----------|-------------|-------|
| `spec_modification` | `*_spec.rb`, `*.test.ts`, etc. | **REQUIRES JUSTIFICATION** |
| `migration` | `db/migrate/*`, `migrations/*` | **CREATE NEW, don't edit deployed** |
| `configuration` | `config/**/*.yml`, `*.env*` | Production impact? Secrets? |
| `api_change` | `*_controller.rb`, `api/**` | Breaking change? Consumers? |
| `security` | Files with auth/security/permission in path | Weakens access controls? |
| `general` | All other files | Purpose? Affects other code? |

## Justification Category Questions

| Category | Key Questions |
|----------|---------------|
| `spec_modification` | Adding new specs? Changing assertions to pass? |
| `migration` | New migration? Editing deployed migration? |
| `configuration` | Production impact? Secrets involved? |
| `api_change` | Breaking change? Consumers to coordinate? |
| `security` | Weakens access controls? Needs security review? |
| `general` | Purpose? Affects other code? |

## Artifact Templates

Templates are located at `$AUTOCODE_PLUGIN_ROOT/templates/artifacts/`:
- `justification.md`, `decision.md`, `assumption.md`, `risk.md`, `debt.md`, `review_hint.md`

The PostToolUse hook creates template artifact files on disk when Edit/Write occurs. The task-runner fills these with real content after agent work completes (Step 6).
